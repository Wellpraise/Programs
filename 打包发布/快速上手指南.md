D:\我的工具\发货单对账工具\

- ✅ `发货单对账工具.py`

## ⚙️ 二、安装依赖(仅需一次)

打开CMD(命令提示符),切换到工具目录:

```cmd
cd D:\我的工具\发货单对账工具
```

然后运行:

```cmd
pip install -r requirements.txt
```

如果遇到 `pyzbar` 安装失败,先安装 ZBar 库:
1. 下载: http://jaist.dl.sourceforge.net/project/zbar/windows/zbar-0.10.exe
2. 安装到默认位置(通常是 `C:\Program Files\ZBar\`)
3. 将 `C:\Program Files\ZBar\bin` 添加到系统PATH环境变量

打开 `对账总表_*.xlsx`,重点关注这几列:

1. **匹配状态**(第9列) - 用Excel筛选"✅ 匹配成功"看正常情况
2. **串号状态**(第8列) - 筛选"🔴 串号"检查异常
3. **所有扫描条码**(第5列) - 查看该照片所有识别到的条码
4. **扫描FBA编码**(第4列) - 19位FBA箱码

## ❓ 六、常见问题

### Q1: 双击BAT文件闪退?

**原因**: Python没加入系统环境变量,或依赖没安装

**解决**: 
1. 先运行 `pip install -r requirements.txt`
2. 再从CMD手动运行: `python 发货单对账工具.py`
3. 查看具体错误信息

### Q2: 照片扫不出条码?

**检查**:
- 照片是否清晰(清晰度>15)
- 条码是否完整可见
- 拍照距离30-50cm
- 避免强光反射

### Q3: 汇总表找不到?

**检查**:
- 文件名是否包含 `发货单_SKU标签汇总`
- 文件是否在 `汇总结果` 文件夹中
- 文件是否为 `.xlsx` 格式

### Q4: 串号太多怎么办?

**处理**:
1. 打开 `串号_*.xlsx`
2. 查看每个FBA编码对应的SKU数量
3. 核对实物:箱子内是否真的混装
4. 如果是数据错误,检查汇总表录入
5. 如果是真实串号,分开装箱
