# 发货单对账工具 v1.2 - 打包发布

## 📦 文件清单

```
打包发布/
├── 发货单对账工具.py      # 主程序(Python源代码)
├── 运行工具.bat           # Windows一键启动脚本
```

## 🚀 快速部署

### 1. 复制到目标电脑

将整个 `打包发布` 文件夹复制到任何位置(支持任意盘符):

```
D:/对账工具/打包发布/
E:/工具/对账工具打包/
```

### 2. 安装依赖

在目标电脑的CMD中运行:

```bash
cd "D:\对账工具\打包发布"
pip install -r requirements.txt
```

> ⚠️ 如果安装 `pyzbar` 失败,需要先安装 ZBar 库:
> - 下载地址: http://jaist.dl.sourceforge.net/project/zbar/windows/zbar-0.10.exe

### 3. 运行工具

**方式A - 双击运行(推荐):**
- 双击 `运行工具.bat`

**方式B - 命令行运行:**
```bash
python 发货单对账工具.py
```

## 📝 使用说明

详细使用文档请阅读: `对账工具完整使用说明.md`

### 核心功能

1. 扫描箱子照片中的FBA条码(19位编码)
2. 从文件夹名推断SKU
3. 与第一步汇总表联动对账
4. 串号检测 + 清晰度评估
5. 自动生成分类Excel报告

### 输出文件

| 文件 | 说明 |
|------|------|
| 对账总表_*.xlsx | 完整报告(最重要) |
| 正常匹配_*.xlsx | ✅ 匹配成功且无串号 |
| 模糊照片_*.xlsx | ⚠️ 照片太模糊需重拍 |
| 无条码_*.xlsx | ❌ 未识别到FBA条码 |
| 未匹配FBA_*.xlsx | ⚠️ FBA不在汇总表中 |
| 串号_*.xlsx | 🔴 重点关注:串号异常 |

## ⚠️ 注意事项

1. **汇总表准备**: 确保第一步工具生成的 `发货单_SKU标签汇总*.xlsx` 存在于 `汇总结果` 文件夹中
2. **照片格式**: 支持 .jpg, .jpeg, .png, .bmp, .tiff, .webp
3. **递归扫描**: 照片文件夹支持多层子目录,工具会自动递归扫描
4. **条码质量**: 照片需清晰可见条码,建议拍照距离30-50cm

## 🆘 常见问题

### Q: pyzbar安装失败?

```bash
# 方法1: conda安装(推荐)
conda install zbar

# 方法2: 下载安装包
# http://jaist.dl.sourceforge.net/project/zbar/windows/zbar-0.10.exe
```

### Q: 照片扫不出条码?

- 确保照片中清晰拍到FBA条码
- 避免模糊、反光、遮挡
- 调整拍照距离(30-50cm)
- 检查照片是否为有效图片格式

### Q: 找不到汇总表?

- 确认汇总表文件名包含 `发货单_SKU标签汇总`
- 确保文件在 `汇总结果` 文件夹中
- 或放在工具同级目录的 `汇总结果` 文件夹
