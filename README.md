# 发货通知单 SKU 标签提取工具

从一批 `.xls` / `.xlsx` 发货通知单文件中提取 **箱子编码(FBA编号)**、**发货单号**、**SKU号** 和 **对应标签**，汇总成一张总表。

---

## 快速开始

### 前提条件

- Python 3.8+ 
- 需要安装以下库：`xlrd`、`pandas`、`openpyxl`

```bash
pip install xlrd pandas openpyxl
```

### 第一步：准备输入文件

将要处理的 `.xls` / `.xlsx` 发货通知单文件放到同一个文件夹中。

```
E:\验货\A0151\input the list\
  ├── A151-发货数据最终版9件-1 不打托(7.3) CHO1.xls
  ├── A151-发货数据最终版9件-2 不打托(7.3) DFW6.xls
  ├── A151-发货数据最终版162件 不打托(7.3) XLX1.xls
  └── ...（更多文件）
```

> **每个文件的格式要求**：
> - 包含名为 **"发货单"** 的工作表
> - A1 单元格 = FBA编号（箱子编码）
> - A4 单元格 = 发货单号
> - 从第13行开始，H列 = SKU号，J列 = 对应标签

### 第二步：修改配置

打开 `发货单SKU提取脚本.py`，修改顶部配置区的两个路径：

```python
INPUT_FOLDER = r"E:\验货\A0151\input the list"        # 👈 改这里：你的输入文件夹
OUTPUT_FOLDER = r"E:\验货\A0151\汇总结果_v3"           # 👈 改这里：你的输出文件夹
OUTPUT_FILENAME = "发货单_SKU标签汇总.xlsx"             # 👈 改这里：输出文件名
```

### 第三步：运行脚本

```bash
python 发货单SKU提取脚本.py
```

### 第四步：查看结果

脚本运行完毕后，在输出文件夹中找到汇总 Excel 文件：

```
E:\验货\A0151\汇总结果_v3\
  └── 发货单_SKU标签汇总.xlsx
```

### 输出字段说明

| 列名 | 说明 | 示例 |
|------|------|------|
| 箱子编码 | 每个文件的 FBA 编号 | `AE-FBA19HBZ8XRK` |
| 发货单号 | 每个文件的发货单号 | `发货单号：A151-001-0703...` |
| SKU号 | H列提取的 SKU 编号 | `SOK010`、`SOB001` |
| 对应标签 | J列提取的标签（自动继承） | `X003VR06AT` |
| 源文件名 | 原始文件名称 | `A151-...XLX1.xls` |

## 工作原理

### 核心规则

每个文件从第13行开始扫描，逐行读取 H 列（SKU号）和 J 列（对应标签），关键逻辑如下：

1. **标签继承**：J列有新标签就刷新，没有新标签就沿用上一个值
2. **空白中断**：连续10行 H 列为空 → 清空当前标签
3. **过滤条件**：
   - SKU 不为空
   - SKU 不含中文（排除"装箱支数"等表头行）
   - 有有效标签

### 示例

```
行13: SKU=SOK049,  J=X003VR04WJ  → 写入  (标签变为 X003VR04WJ)
行14: SKU=SOB016,  J=X003Y6AJ0J  → 写入  (标签刷新为 X003Y6AJ0J)
行15: SKU=空白,    J=空白        → 跳过  (标签仍为 X003Y6AJ0J)
行16: SKU=SOK010,  J=X003VR06AT  → 写入  (标签刷新为 X003VR06AT)
行17: SKU=空白,    J=空白        → 跳过  (标签仍为 X003VR06AT)
...
```

## 常见问题

### Q1：某个文件没有被处理？

检查：
- 文件格式是否为 `.xls` 或 `.xlsx`
- 文件中是否包含名为 **"发货单"** 的工作表
- 脚本运行时会在终端显示 `[跳过] 文件名` 的原因

### Q2：提取的记录数为 0？

检查：
- A1 和 A4 是否有值
- 第13行之后是否有数据
- 确认 H 列和 J 列确实包含 SKU 和标签信息

### Q3：能否增量更新？

目前每次运行都会覆盖输出文件。如果需要增量追加，可以修改脚本末尾的保存逻辑。

### Q4：能处理 `.xlsx` 格式吗？

可以。脚本同时支持 `.xls`（旧格式）和 `.xlsx`（新格式）。

## 技术细节

- **读取库**：`xlrd`（`.xls`旧格式）
- **数据处理**：`pandas`
- **写入库**：`openpyxl`（`.xlsx`新格式）
- **中文检测**：`ord(char) > 255`，判断是否为中文字符
- **最大扫描行数**：1000行（性能优化）
